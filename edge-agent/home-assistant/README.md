# FilamentHub Edge for Home Assistant

[![Add the repository to my Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FWeLizard%2Ffilamenthub-edge-home-assistant)

## Русский

Репозиторий магазина Home Assistant с приложением FilamentHub Edge — мостом
между принтерами в локальной сети и [FilamentHub](https://filamenthub.ru).

1. Нажмите кнопку выше или откройте **Настройки → Приложения → Магазин → меню →
   Репозитории** и добавьте `https://github.com/WeLizard/filamenthub-edge-home-assistant`.
2. Найдите в магазине **FilamentHub Edge** и установите.
3. На вкладке **Конфигурация** добавьте принтер: его адрес и одноразовый код из
   карточки системы подачи на сайте. Сохраните и запустите.

Подробности — на вкладке **Документация** приложения и на
[странице Edge](https://filamenthub.ru/download/edge).

## English

The Home Assistant store repository for FilamentHub Edge, a bridge between the
printers on your local network and [FilamentHub](https://filamenthub.ru).

1. Press the button above, or open **Settings → Apps → Store → menu →
   Repositories** and add `https://github.com/WeLizard/filamenthub-edge-home-assistant`.
2. Find **FilamentHub Edge** in the store and install it.
3. On the **Configuration** tab add a printer: its address and the one-time code
   from the material system card on the site. Save and start.

See the app's **Documentation** tab and the
[Edge page](https://filamenthub.ru/download/edge) for details.

## 中文

FilamentHub Edge 的 Home Assistant 商店仓库。该应用连接本地网络中的打印机与
[FilamentHub](https://filamenthub.ru)。

1. 点击上方按钮，或打开 **设置 → 应用 → 商店 → 菜单 → 仓库**，添加
   `https://github.com/WeLizard/filamenthub-edge-home-assistant`。
2. 在商店中找到 **FilamentHub Edge** 并安装。
3. 在 **配置** 页添加打印机：其地址和网站上送料系统卡片中的一次性代码。保存并启动。

详情见应用的 **文档** 页和 [Edge 页面](https://filamenthub.ru/download/edge)。
